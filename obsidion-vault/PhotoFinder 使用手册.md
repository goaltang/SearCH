# PhotoFinder 使用手册

> 本手册面向**操作者**（部署并运行工具的人）。
> 普通参与者只需发一张自拍照给操作者，无需安装任何东西。

## 典型工作流

```text
参与者发来自拍 ──► 操作者打开 Web UI ──► 添加参考照片 ──► 开始查找
                                                         │
参与者收到 zip ◄── 操作者打包下载 ◄── 结果卡片墙（标注人脸框）◄┘
```

一次活动通常有几十人需要查找。每个人的操作约 1-2 分钟（首次需要下载相册缩略图，后续查找复用缓存，秒出结果）。

---

## 一、启动

```powershell
# 双击 start-webui.bat，或：
.\start-webui.ps1
```

浏览器打开 **http://127.0.0.1:7860**。

> [!tip] 首次启动
> 首次运行某个相册时，需要下载全部缩略图并建立人脸索引。
> 7000 张相册大约需要 10-30 分钟（取决于网速和 CPU）。
> **同一相册的后续查找只需几秒**，因为索引已缓存在本地。

---

## 二、Web UI 操作

### 第 1 步：粘贴相册链接

输入框已预填常用活动链接，直接修改即可。链接格式：

```
https://www.yipai360.com/photolivepc/?orderId=XXXXXXXXXX
```

### 第 2 步：添加参考照片

在"添加参考照片"区域操作，支持两种方式：

| 方式 | 操作 |
|------|------|
| **拍照** | 点击 Webcam 标签 → 允许摄像头 → 点击快门拍照 |
| **上传** | 点击 Upload 标签 → 选择本地图片文件 |

- 拍照/上传后照片**自动加入**上方"已添加的参考照片"列表
- **可反复添加多张**（正脸 + 侧脸效果最好）
- 添加后下方会即时反馈人脸检测质量：
  - ✓ 人脸清晰 → 可用
  - 未检测到人脸 → 换一张
  - 检测到多张人脸 → 自动使用最大的一张
- 加错了？点 **↩ 撤销最后一张** 或 **✕ 清空全部**

> [!important] 参考照片质量直接决定查找效果
> - 清晰正脸 > 侧脸 > 低头/遮挡/墨镜
> - 建议：正脸 1 张 + 侧脸 1 张
> - 背景复杂没关系，系统自动取最大人脸
> - 光线均匀、面部占画面 1/4 以上效果最佳

### 第 3 步：开始查找

点击 **「开始查找」** 按钮。进度条会显示当前阶段：

1. 获取照片列表（首次需要，后续走缓存）
2. 下载照片（首次需要，后续跳过已下载的）
3. 建立人脸索引（首次需要，后续只处理新增的）
4. 相似度检索（每次都很快）

搜索过程中可随时点 **✕ 取消**。

### 第 4 步：查看结果

结果以卡片墙展示：

- **缩略图**：绿框标注了命中的人脸位置
- **相似度分数**：绿色 ≥ 0.6（高置信）、蓝色 ≥ 0.45（中等）、灰色 < 0.45
- **文件名 / photoId**：用于在原网页定位
- **原图链接**：点击可查看/下载原始分辨率照片

### 第 5 步：打包发给参与者

点击 **「📦 打包下载全部命中照片」**，等待下载完成后，下方出现 zip 文件，点击下载。

把 zip 直接发给对应的参与者即可。

## 三、高级选项

展开"高级选项"折叠面板：

| 选项 | 说明 | 建议 |
|------|------|------|
| 相似度阈值 | 越高越严格（漏掉一些），越低越宽松（混入一些） | 默认 0.45 即可；误命中多就调到 0.5-0.55 |
| 最多处理照片数 | 只处理前 N 张，调试用 | 保持 0（全部） |
| 相册密码 | 如果相册设了密码 | 按需填写 |
| 排除的照片 ID | 误命中的照片 ID，逗号分隔 | 从结果卡片上抄 ID 填入，下次搜索自动跳过 |
| 仅拉取新增照片 | 活动进行中，摄影师还在上传 | 勾选后只下载和索引新照片 |

---

## 四、批量帮多人查找

活动场景下通常要帮几十个人找照片。推荐流程：

1. **先跑一次空搜索**（随便放一张参考照），让系统把 7000 张缩略图全部下载并建好索引
2. 之后每个人的查找都**复用缓存**，只需几秒
3. 让参与者把自拍发给你（微信/钉钉均可），保存到本地一个文件夹
4. 依次操作：清空参考照片 → 添加该参与者的照片 → 开始查找 → 打包下载 → 发送
5. 每人约 1 分钟

> [!tip] 效率技巧
> - 让参与者发**原图自拍**，不要发截图或压缩过的图
> - 正脸 + 侧脸各一张，比单张正脸召回率高很多
> - 如果某人总是误命中很多，适当调高阈值（0.5-0.55）

## 五、CLI 命令行

适合脚本化或批量操作：

```powershell
# 基本用法
photofinder --url "相册链接" --ref face.jpg

# 多张参考照 + JSON 输出
photofinder --url "相册链接" --ref front.jpg side.jpg --json

# 增量刷新（活动进行中）
photofinder --url "相册链接" --ref face.jpg --incremental

# 排除误命中
photofinder --url "相册链接" --ref face.jpg --exclude 12345 12346

# 完整参数
photofinder --url "相册链接" --ref face.jpg `
  --threshold 0.5 `
  --max-photos 100 `
  --pwd "密码" `
  --workers 8 `
  --json
```

| 参数 | 说明 |
|------|------|
| `--ref` | 参考照片路径，可多张 |
| `--threshold` | 相似度阈值（默认 0.45） |
| `--max-photos N` | 只处理前 N 张 |
| `--pwd` | 相册密码 |
| `--refresh` | 强制重新拉取照片列表 |
| `--incremental` | 仅拉取新增照片 |
| `--rebuild-index` | 清空索引重建 |
| `--exclude ID...` | 排除指定 photoId |
| `--json` | JSON 格式输出 |
| `--workers N` | 并发数（默认 4） |
| `--min-face N` | 最小人脸宽度 px（默认 24） |
| `--cache` | 缓存目录（默认 cache） |
| `--models` | 模型目录（默认 models） |

## 六、常见问题

### 查找结果太少 / 漏了很多照片

- 换一张更清晰的正脸参考照
- 增加一张侧脸参考照
- 适当调低阈值（0.40-0.42）
- 检查参考照片质量反馈，确认人脸被正确检测

### 查找结果太多 / 很多不是本人

- 调高阈值（0.50-0.55）
- 在结果卡片上找到误命中的 photoId，填入"排除的照片 ID"
- 换一张背景更干净的参考照（避免多人合照做参考）

### 搜索很慢

- 首次运行需要下载全部缩略图 + 建索引，这是正常的
- 同一相册第二次搜索会非常快（秒级）
- 如果有 NVIDIA 显卡，安装 `onnxruntime-gpu` 可大幅加速
- 调高 `--workers` 参数（如 8）可加速索引构建

### 摄像头打不开 / 关不了

- 浏览器需要授权摄像头权限（地址栏左侧锁图标）
- 切到 Upload 标签页即可关闭摄像头
- 如果摄像头卡住，刷新页面重来

### OSS 链接过期 / 图片加载不出来

- 签名 URL 有时效性，过期后重新运行搜索即可刷新
- 打包下载时如果全部失败，会提示"链接可能过期"

### 模型下载失败

手动下载 `buffalo_l.zip`：
https://github.com/deepinsight/insightface/releases/download/v0.7/buffalo_l.zip

解压到 `models/` 目录，确保包含 `det_10g.onnx` 和 `w600k_r50.onnx`。

## 七、隐私说明

- **所有计算在本地完成**，照片和人脸特征不会上传到任何服务器
- 唯一的外部请求是访问 yipai360 的相册 API 下载照片
- 用完后删除 `cache/` 目录即可清理全部本地数据
- 请确保获得被查找者的同意后再使用
